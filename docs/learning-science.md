# Evidence and product decisions

Lumen distinguishes established learning findings from implementation hypotheses. None of these studies measures Lumen itself or validates a particular AI-generated note.

| Finding                                                                                   | Product behavior                                                  | Scope                                                                                                                                                                             |
| ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Retrieval practice improves delayed retention in studied conditions.                      | Attempt an answer before revealing a suggested answer.            | [Roediger & Karpicke, 2006](https://doi.org/10.1111/j.1467-9280.2006.01693.x).                                                                                                    |
| Useful spacing depends on the target retention interval.                                  | Revisit questions over time; record attempts and due dates.       | [Cepeda et al., 2008](https://laplab.ucsd.edu/articles/Cepeda%20et%20al%202008_psychsci.pdf). The initial scheduling rule is an engineering heuristic, not a fitted memory model. |
| Prompted self-explanation can improve understanding.                                      | Explanation questions ask why an idea works and where it applies. | [Chi et al., 1994](https://doi.org/10.1207/s15516709cog1803_3). Effects depend on context and explanation quality.                                                                |
| Interleaved practice can improve mathematics learning.                                    | Alternate available questions across notes.                       | [Rohrer et al., 2020](https://uweb.cas.usf.edu/~drohrer/pdfs/Rohrer_et_al_2020JEdPsych.pdf). Arbitrary mixing of technical notes is an unvalidated application of this idea.      |
| Retrieval can support transfer to new inference questions.                                | Store application tasks separately from recall.                   | [Butler, 2010](https://pubmed.ncbi.nlm.nih.gov/20804289/). This does not imply unlimited transfer across domains.                                                                 |
| Practice testing and distributed practice have stronger broad support than summarization. | Summaries organize reference material; attempts provide practice. | [Dunlosky et al., 2013](https://journals.sagepub.com/stoken/rbtfl/Z10jaVH/60XQM/full). The review does not test AI summaries.                                                     |

## Explicit design hypotheses

- A roughly 100–180-word core summary is a practical default, not a research-derived ideal length.
- An eight-question session cap is a convenience, not an optimal dose.
- The initial interval multipliers are transparent heuristics. They are not FSRS, a calibrated forgetting curve, or a prediction of mastery.
- Self-ratings are saved as such. The app does not claim objectively verified understanding.
- Reference-only notes create no review obligation. Users decide which ideas are worth practicing.

## Personal evaluation

Assign comparable new topics at random to the usual learning workflow or Lumen. Record prior knowledge and time spent, including note preparation. Assess both unaided recall and performance on a new problem after 7 and 30 days. Use the same test timing in both conditions because a test itself provides practice. Compare retention and application per minute, report uncertainty, and repeat across topics before inferring a benefit.

This is an evaluation proposal; no experiment has been run and no speedup is claimed.
