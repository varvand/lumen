# Third-party assets

The application icon and UI glyphs use **Phosphor Icons**, distributed under the MIT license. The application icon uses the regular SunHorizon path from `phosphor-svelte`, with a colored background and scaling. See the installed package's LICENSE and https://github.com/phosphor-icons.

**DM Sans**, **Newsreader**, and **IBM Plex Mono** are bundled through Fontsource. Their package license files accompany the installed dependencies. **KaTeX** includes its own math fonts and license. All are served locally; no remote font request is needed.
